Flags are from [flag-icons](https://github.com/lipis/flag-icons) (MIT), 4x3.
`es.svg` is the Spanish civil flag (plain bands) instead of the state flag —
the upstream file is 91 KB of coat-of-arms detail that is invisible at 18 px.

To add a country: drop `<alpha-2>.svg` here and add a line to the `FLAG`
table in `js/footprint.js`.
